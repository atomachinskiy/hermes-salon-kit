# Расшифровка голосовых в Hermes: проверка и настройка

Инструкция для тебя, агента Hermes. Человек хочет, чтобы ты понимал его голосовые: в Telegram и в окне Hermes. Голос расшифровывается на этом компьютере через Local Whisper (faster-whisper), без ключей и без оплаты. Но faster-whisper не ставится вместе с Hermes, его нужно доустановить.

## Как общаться с человеком

- По-русски, на «вы», простыми словами. Не используй слова «конфиг», «терминал», «пакет», «зависимости».
- Перед действием одной фразой скажи, что делаешь. Если Hermes покажет «Требуется одобрение», попроси нажать «Одобрить».
- Ничего не удаляй, не меняй модель и вход в ChatGPT. Не больше двух обходов на шаг: не вышло, скажи об этом и что помогут ведущие.

## Шаг 1. Проверка (сначала только смотрим, ничего не меняем)

1. Система и процессор:
   - Windows: `echo %PROCESSOR_ARCHITECTURE%` (в PowerShell `$env:PROCESSOR_ARCHITECTURE`). AMD64 = обычный, ARM64 = ARM.
   - Mac: `uname -m`. arm64 = Apple M1–M4, x86_64 = Intel.
2. `hermes config path` покажет config.yaml. Прочитай в нём раздел `stt`: `enabled`, `provider`, `language`, `local.model`, `local.language`.
3. Установлен ли faster-whisper: поищи папку `faster_whisper` внутри папки, где лежит config.yaml, и во всех вложенных (на Windows это `%LOCALAPPDATA%\hermes`).
4. Покажи человеку короткую таблицу: система, голосовые включены (да/нет), какой способ расшифровки выбран, язык, faster-whisper установлен (да/нет).

## Шаг 2. Можно ли поставить на этот компьютер

- Windows ARM64 или Mac на Intel (x86_64): faster-whisper на них не работает. Скажи человеку: «На этом компьютере голос расшифровать локально нельзя, ведущие подключат облачную расшифровку». Остальные шаги не делай.
- Windows AMD64 или Mac arm64: иди дальше.

## Шаг 3. Установка (если faster-whisper не нашёлся)

1. Скажи: «Ставлю расшифровку голоса, это 2–5 минут».
2. `hermes pm install --extra stt-whisper`
3. Если команда упала, попроси человека сделать то же кнопкой: слева «Возможности» → «Инструменты» → Speech-to-Text → строка Local Whisper → «Запустить настройку». Дождаться окончания.
4. Если на Windows в ошибке есть «Отказано в доступе», EPERM или «не удается открыть файл», это антивирус. Не обходи его сам, скажи, что поможет ведущий.

## Шаг 4. Настройки

```
hermes config set stt.enabled true
hermes config set stt.provider local
hermes config set stt.language ru
hermes config set stt.local.language ru
hermes config set stt.local.model small
```

Модель `small` понимает русский заметно лучше стандартной `base`. Она скачается сама при первом голосовом, около 460 МБ.

## Шаг 5. Перезапуск

Новая расшифровка заработает только после перезапуска. Попроси человека: значок Hermes возле часов (на Mac в строке меню) → «Выйти», затем снова открыть Hermes. Если работает бот в Telegram, после запуска: Ctrl+K → «Перезапустить шлюз».

## Шаг 6. Проверка вживую

Попроси человека записать своему боту в Telegram голосовое: «Раз, два, три, проверка связи». Бот сначала пришлёт расшифровку со значком 🎙️, потом ответит. Первое голосовое может идти до минуты: качается модель. Если расшифровки нет, попроси прислать скрин ведущим.

Сохрани в память: «Голосовые расшифровываются локально, Local Whisper, модель small, русский язык».
