# Настройка Hermes для владельца салона

Инструкция для тебя, агента Hermes. Её дали ведущие воркшопа «Нейросети для бьюти-бизнеса» (Андрей Томачинский), и человек попросил тебя настроиться по ней. Выполняй шаги по порядку.

## Как общаться с человеком

- Говори по-русски, на «вы», простыми словами. Человек не технический: не используй слова «конфиг», «терминал», «бэкенд», «токен», «MCP», «зависимости».
- Один шаг за раз. Перед действием одной фразой скажи, что делаешь и зачем.
- Если Hermes покажет «Требуется одобрение», попроси человека нажать «Одобрить».
- Если шаг не получился, не ломай настройки и не пробуй больше двух обходов. Коротко скажи, что не вышло, отметь шаг ❌ и иди дальше. С этим помогут ведущие.
- Ничего не удаляй. Не меняй модель, вход в ChatGPT и способ авторизации.
- Если в ошибке на Windows есть «Отказано в доступе», «EPERM», «operation not permitted» или «не удается открыть указанное устройство или файл», это антивирус блокирует установку. Не обходи его сам: отметь шаг ❌ с пометкой «антивирус» и иди дальше.

## Шаг 0. Где ты живёшь

1. Определи систему и процессор. Windows: `$env:PROCESSOR_ARCHITECTURE` в PowerShell (AMD64 обычный, ARM64 это ARM). Mac: `uname -m` (arm64 это Apple M1–M4, x86_64 это Intel).
2. Найди команду `hermes`: `hermes --version`. Если её нет: на Windows `"$LOCALAPPDATA/hermes/bin/hermes.exe"` (в PowerShell `& "$env:LOCALAPPDATA\hermes\bin\hermes.exe"`), на Mac `~/.local/bin/hermes`. Дальше в инструкции везде `hermes`, подставляй найденный путь.
3. `hermes config path` покажет путь к config.yaml. Папка, где он лежит, это твой дом (HERMES_HOME). Скиллы живут в `<HERMES_HOME>/skills`.

## Шаг 1. Русский язык и голосовые

Голос расшифровывается на этом компьютере через Local Whisper (faster-whisper), бесплатно и без ключей. Но faster-whisper не ставится вместе с Hermes, его нужно доустановить.

1. Сохрани в память: «Пользователь владелец или управляющий салона красоты (клиники, СПА). Всегда отвечай ему по-русски, простыми словами».
2. Проверь, установлен ли faster-whisper: поищи папку `faster_whisper` внутри HERMES_HOME и во всех вложенных.
3. Если система Windows ARM64 или Mac на Intel (x86_64), faster-whisper на ней не работает. Отметь «Голосовые» ❌ с пометкой «нужна облачная расшифровка, помогут ведущие» и переходи к пункту 6.
4. Если faster-whisper нет: скажи «Ставлю расшифровку голоса, это 2–5 минут» и выполни `hermes pm install --extra stt-whisper`. Если команда упала, попроси человека: слева «Возможности» → «Инструменты» → Speech-to-Text → строка Local Whisper → «Запустить настройку».
5. Настройки расшифровки:
   ```
   hermes config set stt.enabled true
   hermes config set stt.provider local
   hermes config set stt.local.model small
   hermes config set stt.local.language ru
   ```
   Модель `small` понимает русский заметно лучше стандартной `base`, скачается сама при первом голосовом (около 460 МБ).
6. В любом случае: `hermes config set stt.language ru`. Без этого голосовые расшифровываются как английская речь.

Голосовые заработают после перезапуска Hermes в шаге 7.

## Шаг 2. Скиллы для салона

Нужна папка `skills` из этого набора: 26 скиллов. Арт-директор для визуала салона (art-direktor), 12 под стратегию и маркетинг (product-marketing, swot-analysis, price-check, customer-journey-map, analiz-konkurentov, campaign-plan, kontent-plan, social, offers, sms, generaciya-kreativov, carousel-writer-sms) и 13 для Instagram (ig-reel, ig-viral, ig-caption, ig-carousel, ig-story, ig-profile, ig-plan, ig-human, ig-comment, ig-reply, ig-dm, ig-repurpose, ig-audit).

1. Если набор уже лежит у человека на компьютере (распакованный архив или папка `hermes-salon-kit`), возьми `skills` оттуда.
2. Если нет, скачай архив: `https://github.com/atomachinskiy/hermes-salon-kit/archive/refs/heads/main.zip`. Качай именно архив одним файлом (curl, PowerShell Invoke-WebRequest или Python). Не ставь скиллы по одному через `hermes skills install`: у GitHub лимит запросов, на воркшопе весь зал в одной сети.
3. Распакуй любым доступным способом (unzip, PowerShell Expand-Archive, Python zipfile) и скопируй содержимое папки `skills` в `<HERMES_HOME>/skills/salon-skills/`. Должно получиться `<HERMES_HOME>/skills/salon-skills/<имя-скилла>/SKILL.md`.
4. Проверь: `hermes skills list` показывает все 26. Если какого-то нет, проверь путь.
5. Скиллы Instagram читают файл голоса автора `~/.claude/instagram/voice.md` (папка в домашней папке пользователя, на Windows тоже). Скопируй туда `instagram/voice.md` из набора. Заполнять сейчас не нужно: на практике человек пришлёт ссылки на свои посты, и ты заполнишь его по ним. Скиллы Instagram ничего не публикуют сами, только пишут тексты.

## Шаг 3. Картинки через подписку ChatGPT

1. `hermes config set image_gen.provider openai-codex`. Это gpt-image-2 через подписку ChatGPT, ключи не нужны.
2. Не трогай другие провайдеры картинок, они платные.

## Шаг 4. Поиск в интернете и браузер

1. Сделай один пробный поиск, например «салоны красоты Москва Электрозаводская». Если ответ пришёл, ничего не меняй.
2. Если поиск упал с лимитом или ошибкой: `hermes config set web.search_backend openai-native`. Поиск пойдёт через подписку ChatGPT.
3. Открой браузером https://ya.ru и прочитай заголовок страницы. Если браузерного инструмента нет, попроси человека: слева «Возможности» → «Инструменты» → Browser Automation → строка Local Browser → «Запустить настройку».
4. `hermes config set browser.headed true`. Тогда человек видит окно браузера и при капче может пройти её сам.

## Шаг 5. Google

Карточек Google в «Возможности» → Connectors у участников нет, поэтому подключаем через твой встроенный скилл `google-workspace` и готовое приложение ведущих.

1. Если в сообщении человека есть ссылка на файл приложения Google (`https://bk.ideafromai.ru/g/.../hermes-google.json`), подключи Google по инструкции https://raw.githubusercontent.com/atomachinskiy/hermes-salon-kit/main/GOOGLE.md с этой ссылкой.
2. Если ссылки нет, не создавай проект в Google Cloud: отметь Google ❌ с пометкой «нужна ссылка от ведущих» и иди дальше.

## Шаг 6. Свой агент в Telegram

Это человек делает руками, ты ведёшь по шагам и ждёшь подтверждения после каждого:

1. «Настройки» → «Внешний вид» → включить «Сворачивать в трей». Тогда агент работает, даже если закрыть окно крестиком.
2. Слева «Сообщения» → Telegram → блок «Быстрая настройка» → «Создать по QR».
3. Отсканировать QR телефоном (или нажать «Открыть Telegram») и подтвердить создание бота.
4. Когда появится «Бот создан», нажать «Сохранить и перезапустить».

Скажи человеку: бот отвечает, пока компьютер включён и VPN работает. Если QR истёк, начать заново.

## Шаг 7. Перезапуск и итог

1. Попроси человека полностью перезапустить Hermes: значок Hermes возле часов (на Mac в строке меню) → «Выйти», затем снова открыть Hermes. Если бот в Telegram не отвечает после запуска: Ctrl+K → «Перезапустить шлюз».
2. Проверка голоса: человек записывает своему боту в Telegram голосовое «Раз, два, три, проверка связи». Бот сначала пришлёт расшифровку со значком 🎙️, потом ответит. Первое голосовое может идти до минуты: качается модель.
3. Покажи короткую таблицу: шаг и ✅ или ❌ (с пометкой, если ❌). Шаги: русский язык, голосовые, скиллы (сколько из 26), картинки, поиск, браузер, Google, Telegram.
4. Скажи: «В новом чате новые настройки и скиллы уже работают».
5. Предложи первую задачу: «Давайте соберём карточку вашего салона. Пришлите ссылку на сайт, Яндекс Карты и соцсети».
